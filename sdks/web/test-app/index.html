Quick start

Follow these five steps to see the whole loop end to end. The checklist ticks as you go, or run the whole thing at once.

  1. ✓ Check the receiver is up — the status chip in the header shows receiver ok.
  2. ✓ Trigger a bug — use a scenario card below, or the golden-path button.
  3. ✓ Open the form — the launcher bottom-right, or Ctrl + Enter.
  4. ✓ Send the report — describe the problem and press Send.
  5. ✓ Read the report — it appears in Output below.
